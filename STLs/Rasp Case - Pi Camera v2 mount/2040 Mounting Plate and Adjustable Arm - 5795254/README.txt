 REMIX of https://www.thingiverse.com/thing:4761307 by crsn00   I wanted an option to side mount this assembly to my Ender-3 Pro and needed a project to start learning Fusion 360. The 2040 mounting plate uses 2- M4 x 10 socket head cap screws, 2 washers, and 2 T-Nuts to mount to the extrusion. The washers need to be press-fit into the mounting plate using the M4 screws.
